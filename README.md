# astra-foundation-foo-engine

**Staging test foundation — not for players.**

A FOUNDATION for the fictional engine `foo-engine`: it exists only to rehearse
the Astra games catalogue's staging "done when" (a non-owner account
publishes a foundation that owns a new engine code, and it gets signed into
the index) end to end, as a real third-party author would have to. There is
no real `foo-engine` — its detection rule and the `foo_runtime.dll` marker it
looks for are fixtures, matching
`astra-games-catalogue/fixtures/staging/foo-engine.toml`.

Published from the `astra-test-author` GitHub organisation, a test
organisation the owner created for exactly this kind of walk — it is not
`mihailinl`, so ingest treats it as a non-first-party (community) release.
